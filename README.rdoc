= Docheck

Domain name availability checker. Docheck checks a name against generic TLDs
and reports which domains are available and which are registered.

Docheck uses RDAP (RFC 9082/9083), the protocol that replaced WHOIS for gTLDs.
It sends one HTTPS request per TLD to the registry's RDAP server, all in
parallel. It has no runtime dependencies.

== Requirements
Ruby >= 3.2

== Installation

  $ gem install docheck

== Usage
From the command line:

  $ docheck -n google

The command exits with status 0 on success and 64 on a usage error or an
invalid name.

From Ruby:

  require "docheck"

  results = Docheck.check("github")
  results.first          # => #<data Docheck::Result domain="github.com", status=:registered>
  results.select(&:available?).map(&:domain)

  # Custom TLDs and deadline (seconds for the whole check)
  checker = Docheck::Checker.new(tlds: %w[com net io], deadline: 5)
  checker.check("github")

Each Docheck::Result has a +status+:

* +:available+ - the registry has no record of the domain
* +:registered+ - the registry has a record of the domain
* +:unknown+ - the lookup failed (timeout, rate limit, or server error)
* +:unsupported+ - the TLD has no RDAP server in the IANA bootstrap data

Docheck::Checker#check raises Docheck::InvalidNameError when the name is not a
single DNS label (1-63 letters, digits, or hyphens). Pass IDNs in punycode
(+xn--...+).

The 1.x API (Docheck::Application with +fetch+, +available_domains+,
+registered_domains+, and +print+) still works.
